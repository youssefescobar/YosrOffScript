# YOSROFFSCRIPT

Portfolio site for Yosr — visual storyteller. Live at <https://yosroffscript.me>.

Plain JavaScript + [Vite](https://vite.dev) + [GSAP](https://gsap.com). Films are
hosted separately on a media CDN (Cloudflare R2 at `media.yosroffscript.me`).

## Getting started

```sh
npm install
npm run dev       # local dev server
npm run build     # production build → dist/
npm run preview   # serve dist/ locally
```

Before pushing:

```sh
npm run lint          # ESLint
npm run format        # Prettier (CI runs format:check)
```

CI (`.github/workflows/ci.yml`) runs lint, format check and build on every push.

## Project layout

| ------------------------- | --------------------------------------------------------------- |
| `index.html`              | Page markup, meta tags, structured data                         |
| `src/projects.js`         | **Portfolio content** — categories, films, titles, brands       |
| `src/media-manifest.json` | Generated by `encode` — file names, sizes, durations            |
| `src/main.js`             | Entry point; wires the modules below together                   |
| `src/router.js`           | URL ⇄ view (`/`, `/about`, `/<category>`, `/<category>/<film>`) |
| `src/categories.js`       | Category cards, entering/leaving a category, footer filters     |
| `src/grid.js`             | Film grid, idle preview loops, card hover                       |
| `src/detail.js`           | Film detail overlay                                             |
| `src/about.js`            | About panel                                                     |
| `src/loader.js`           | Intro loader and asset preloading                               |
| `src/state.js`            | Shared DOM refs, view state, helpers                            |
| `src/style.css`           | All styles                                                      |
| `src/assets/`             | About photos (bundled and hashed by Vite)                       |
| `public/`                 | Copied as-is: category covers, favicon, share image, robots.txt |
| `scripts/`                | Media encode + upload                                           |

## Editing content

Titles, brands, descriptions and order live in `src/projects.js`:

```js
{ slug: 'fashion-casa-lila', category: 'fashion', title: 'Casa Lila', brand: 'Casa Lila', description: '…' },
```

- `slug` must match an entry in `src/media-manifest.json` (created by `encode`).
- The film's URL is the slug without its category prefix: `/fashion/casa-lila`.
- `brand` and `description` are optional; empty ones are hidden. The description
  is also used as the page's search/share description.
- A category with no films is hidden everywhere. To add one, add it to
  `ALL_CATEGORIES` in `src/projects.js` and a matching filter button in
  `index.html`.

## Adding or replacing films

Needs `ffmpeg` and `ffprobe` on your PATH (or set `FFMPEG_DIR`).

1. Put the source videos in one folder per category (folder names are mapped
   to categories in `FOLDER_TO_CATEGORY` in `scripts/encode.mjs`).
2. Encode:

   ```sh
   npm run encode -- --src "C:\path\to\Portfolio Projects"
   # or: set PORTFOLIO_SRC once and run `npm run encode`
   ```

   For each video this writes to `media-out/` a 1080p film, a short muted
   preview loop and a poster, and updates `src/media-manifest.json`.
   Unchanged sources are skipped; add `--force` to re-encode everything.
   To pick a different poster frame, create `scripts/poster-overrides.json`:
   `{ "<slug>": <seconds> }`.

3. Check it locally with `npm run dev` — dev serves `media-out/` at `/media/`.
4. Upload to R2 (one-time `npx wrangler login` first):

   ```sh
   npm run upload
   ```

5. Add the film to `ENTRIES` in `src/projects.js`, commit, and deploy.

Set `VITE_MEDIA_BASE` to point a build at a different media host.

## Deploying

`npm run build` writes a static site to `dist/`. Besides `index.html` it writes
one HTML page per category and film (`dist/fashion.html`,
`dist/fashion/casa-lila.html`, `dist/about.html`) with that page's own title,
description, share image and structured data, plus `sitemap.xml`.

The host must:

- serve `/fashion/casa-lila` from `fashion/casa-lila.html` (Cloudflare Pages,
  Netlify and GitHub Pages do this by default; on Vercel set `cleanUrls: true`);
- fall back to `index.html` for any other path.

Old `#portfolio/...` links still work — they are redirected to the new paths.
